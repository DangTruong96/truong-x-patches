# Bản vá Morphe cho X (Twitter) (bản cá nhân)

Bundle `.mpp` cho Morphe Manager. Hỗ trợ X 12.19.1-release.0 (com.twitter.android, bản APKM).

Thêm vào Morphe Manager: https://morphe.software/add-source?github=DangTruong96/truong-x-patches

Nguồn gốc: Piko by crimera (GPL-3.0) — 75 patch cho X (bản 3.10.0): xoá quảng cáo, bỏ upsell Premium, tải media gốc, ẩn các mục gây nhiễu trên timeline và nhiều tuỳ biến giao diện. Bundle này còn chứa các patch Instagram của Piko (không dùng tới ở repo này). Chỉ dùng cá nhân.

Lưu ý: APK vá bằng Morphe Manager được ký bằng keystore trong Manager của bạn; APK vá sẵn do chủ repo gửi riêng được ký bằng keystore khác — với mỗi app, hãy chọn một đường và dùng nhất quán để các bản cập nhật cài đè được lên nhau.
